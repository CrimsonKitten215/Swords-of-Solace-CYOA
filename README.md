# Swords of Solace CYOA
A text-based CYOA about a teenager who finds some really annoying swords.

Currently a WIP, and written up to chapter 5. To play, run the SoS.html file.

There is a flowchart of the routes attached, if you want to use it, though it's recommended to play without first and only use it later to have an easier time finding other routes.

This is the PUBLIC version – for people given access to the private version, use that one (this one's content is more restricted).

## DISCLAIMER:
There are/will be in the future descriptions of gore/murder/etc., so bear that in mind. Also, there is some light swearing occasionally (there will be a toggle for it in the future), and allusions to depression, abuse, and toxic relationships in general. If you feel you may be triggered by this, then I don't recommend playing.
